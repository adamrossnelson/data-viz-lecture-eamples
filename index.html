Visuals To Show When Lecturing About Data Visualization Stories

Seven kinds of data stories, each with candidate visuals to choose from

How To Use This Page

This page is designed to stand in for slides. Every data story type below has several candidate visuals. Each candidate is numbered, captioned, and shows the code that produced it, so you can pick the ones that best fit your lecture and your audience.

Every example uses Seaborn and Matplotlib. Wherever possible the data come from Seaborn’s built-in example datasets. Where no built-in dataset makes the point (review summaries, dials, a battery gauge), the data are fictional and are generated in plain sight in the code.

Story type The question it answers Typical visuals
Comparison How do groups differ? Side-by-side box or violin plots, bar charts
Change over time What happened, and when? Line charts, one violin per year
Correlation Do two things move together? Scatter, hexbin, heat map
Distribution What does one variable look like? Histogram, solo box, solo violin
Composition What are the parts of the whole? Pie, stacked bar, 100% stacked bar
Ranking Who or what is best, and who is worst? Leader boards, review summaries
Process or status Where are we right now? Dials, meters, Sankey, battery

Setup

All figures share the same imports and the same Seaborn context.

# Import Pandas, Seaborn, and related
import pandas as pd
import seaborn as sns
import numpy as np
import matplotlib.pyplot as plt

# Set the Seaborn context
sns.set_context('talk')

The Comparison Stories

A comparison story answers the question how do these groups differ? The reader should be able to see, in a glance, which group is higher, lower, or more spread out. Side-by-side box plots and violin plots show the whole distribution for each group. Bar charts reduce each group to a single number, which is simpler but hides spread.

Candidates: Figure 1, Figure 3, Figure 4, Figure 5.

# Load the example datasets used in this section
penguins = sns.load_dataset('penguins')
tips = sns.load_dataset('tips')
mpg = sns.load_dataset('mpg')
titanic = sns.load_dataset('titanic')

Candidate 1: Side-by-Side Box Plots

A box plot reduces each group to five numbers (minimum, quartiles, median, maximum) and flags outliers. It is the quickest way to compare centers and spreads.

# Compute the median body mass of each species
medians = penguins.groupby('species')['body_mass_g'].median()

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Box plot of body mass by species
sns.boxplot(data=penguins, x='species', y='body_mass_g',
            order=medians.index, hue='species',
            palette='pastel', legend=False, ax=ax)

# Label the median of each box
for i, m in enumerate(medians):
    ax.text(i, m, '{:,.0f} g'.format(m),
            ha='center', va='center', size='xx-small',
            bbox=dict(boxstyle='round', fc='white', ec='none', alpha=0.8))

# Set the title and axis labels
ax.set_title('Gentoo Are Heavier Than Others')
ax.set_xlabel('Penguin Species')
ax.set_ylabel('Body Mass (grams)')

plt.show()

Candidate 2: Side-by-Side Violin Plots

A violin plot adds the shape of each distribution. The inner box keeps the familiar quartile summary while the outline reveals skew and multiple peaks.

# Compute the mean bill for each day
mean_bill = tips.groupby('day', observed=True)['total_bill'].mean()

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Violin plot of total bill by day
sns.violinplot(data=tips, x='day', y='total_bill',
               order=mean_bill.index, hue='day', inner='box',
               palette='pastel', legend=False, ax=ax)

# Label the mean of each violin along the top
for i, m in enumerate(mean_bill):
    ax.text(i, 58, 'Mean\n${:.2f}'.format(m),
            ha='center', va='center', size='small')

# Make room for the labels
ax.set_ylim(0, 65)

# Set the title and axis labels
ax.set_title('Weekend Bills Are Larger Than Weekday Bills')
ax.set_xlabel('Day of the Week')
ax.set_ylabel('Total (Dollars)')

plt.show()

Candidate 3: Bar Chart of Group Averages

When the audience only needs the headline number, a bar chart with height labels is the clearest choice. Remember that the bars hide the spread within each group.

# Compute the average miles per gallon by origin
avg_mpg = mpg.groupby('origin')['mpg'].mean().sort_values(ascending=False)

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Bar chart of average mpg by origin
sns.barplot(x=avg_mpg.index.str.title(), y=avg_mpg.values,
            hue=avg_mpg.index.str.title(), palette='pastel',
            legend=False, ax=ax)

# Add height labels above the bars
for i, v in enumerate(avg_mpg):
    ax.text(i, v + 0.5, '{:.1f}'.format(v),
            ha='center', size='x-large')

# Set the title and axis labels
ax.set_title('Japanese Cars Lead in Fuel Efficiency')
ax.set_xlabel('Region of Vehicle Origin')
ax.set_ylabel('Average (MPG)')
ax.set_ylim(0, 36)

plt.show()

Candidate 4: Grouped Bar Chart

A grouped bar chart compares groups across a second categorical variable. Keep the number of bars manageable so each height label stays readable.

# Compute the survival rate (as a percent) by class and sex
survival = (titanic.groupby(['pclass', 'sex'])['survived']
            .mean().mul(100).reset_index())

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 4))

# Grouped bar chart of survival rate
sns.barplot(data=survival, x='pclass', y='survived',
            hue='sex', palette='pastel', ax=ax)

# Add height labels above each bar
for container in ax.containers:
    ax.bar_label(container, fmt='%.0f%%', padding=3, size='medium')

# Set the title and axis labels
ax.set_title('Women Survived at Higher Rates Than Men')
ax.set_xlabel('Passenger Class')
ax.set_ylabel('Survival Rate (%)')
ax.set_ylim(0, 110)
ax.legend(loc='upper right')

plt.show()

The Change Over Time Stories

A change over time story answers what happened, and when? Time goes on the horizontal axis and the eye follows the line. Line charts are the default. When the audience needs to see how the whole distribution shifted, one violin or box plot per period works well.

Candidates: Figure 6, Figure 7, Figure 8, Figure 9, Figure 10, Figure 11.

# Load the example datasets used in this section
flights = sns.load_dataset('flights')
health = sns.load_dataset('healthexp')
dowjones = sns.load_dataset('dowjones')
fmri = sns.load_dataset('fmri')
mpg = sns.load_dataset('mpg')

Candidate 1: Simple Line Chart With Point Labels

One series, one story. Markers and data labels let the audience read exact values without hunting for gridlines.

# Total the monthly passengers into an annual figure
annual = flights.groupby('year')['passengers'].sum().reset_index()

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Line chart of annual passengers
sns.lineplot(data=annual, x='year', y='passengers',
             marker='o', markersize=9, ax=ax)

# Label each point
for _, row in list(annual.iterrows())[1::3]:
    ax.text(row['year'], row['passengers'] + 350,
            '{:,.0f}'.format(row['passengers']),
            ha='center', size='x-small')

# Set the title and axis labels
ax.set_title('Air Travel Grew Rapidly From 1949 To 1960')
ax.set_xlabel('Year')
ax.set_ylabel('Total Passengers (thousands)')
ax.set_xticks(annual['year'])
ax.set_xticklabels(annual['year'], rotation=45)
ax.set_ylim(0, 6600)

plt.show()

Candidate 2: Multiple Lines With Direct Labels

Labeling the end of each line removes the need to match colors against a legend, which is much easier to follow on a projector.

# Assign one color to each country
health = health[health['Country'].isin(['Japan','Germany','USA'])]
countries = health['Country'].unique()
palette = dict(zip(countries, sns.color_palette('tab10', len(countries))))

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 4))

# One line per country
sns.lineplot(data=health, x='Year', y='Life_Expectancy',
             hue='Country', palette=palette, linewidth=3,
             legend=False, ax=ax)

# Label the end of each line
for country, group in health.groupby('Country'):
    last = group.loc[group['Year'].idxmax()]
    ax.text(last['Year'] + 0.7, last['Life_Expectancy'], country,
            color=palette[country], va='center', size='small')

# Make room for the labels
ax.set_xlim(1970, 2032)

# Set the title and axis labels
ax.set_title('Japan Pulled Ahead on Life Expectancy')
ax.set_xlabel('Year')
ax.set_ylabel('Life Expectancy (years)')

plt.show()

Candidate 3: Annotated Line Chart

An annotation turns a line into a story by pointing at the moment that matters.

# Find the 1929 peak and the low that followed
early = dowjones[dowjones['Date'] < '1940-01-01']
peak = early.loc[early['Price'].idxmax()]
after = early[early['Date'] > peak['Date']]
low = after.loc[after['Price'].idxmin()]

# Find the first month the average climbed back to the peak
recovery = dowjones[(dowjones['Date'] > low['Date']) &
                    (dowjones['Price'] >= peak['Price'])].iloc[0]

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 4))

# Line chart of the Dow Jones average
sns.lineplot(data=dowjones, x='Date', y='Price', ax=ax)

# Annotate the peak, the low, and the recovery
ax.annotate('Sep 1929 peak: {:.0f}'.format(peak['Price']),
            xy=(peak['Date'], peak['Price']),
            xytext=(pd.Timestamp('1916-01-01'), 600),
            arrowprops={'arrowstyle': '->'}, size='xx-small')
ax.annotate('1932 low: {:.0f}'.format(low['Price']),
            xy=(low['Date'], low['Price']),
            xytext=(pd.Timestamp('1933-01-01'),325),
            arrowprops={'arrowstyle': '->'}, size='xx-small')
ax.annotate('Recovered in {}'.format(recovery['Date'].year),
            xy=(recovery['Date'], recovery['Price']),
            xytext=(pd.Timestamp('1938-01-01'), 700),
            arrowprops={'arrowstyle': '->'}, size='xx-small')

# Set the title and axis labels
ax.set_title('Dow Took 25 Yrs to Recover From 1929 Crash')
ax.set_xlabel('Year')
ax.set_ylabel('Dow Jones Average')

plt.show()

Candidate 5: One Violin Per Year

When a line of averages would hide how the whole distribution moved, draw one violin per period. The line over the violins carries the median.

# Compute the median mpg for each model year
yearly_median = mpg.groupby('model_year')['mpg'].median()

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 4))

sns.violinplot(data=mpg, x='model_year', y='mpg', ax=ax)

ax.set_title('Fuel Efficiency Jumped After 1979')
ax.set_xlabel('Model Year')
ax.set_ylabel('Fuel Efficiency (MPG)')
ax.set_xticks(range(len(yearly_median)))

Candidate 6: One Line Per Year to Reveal Seasonality

Drawing each year as its own line, with a sequential color scale, reveals a repeating pattern and shows whether it is growing.

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(5.5, 3))

# One line per year, colored on a sequential palette
sns.lineplot(data=flights, x='month', y='passengers',
             hue='year', palette='viridis', linewidth=2.5, ax=ax)

# Move the legend outside the graph area
ax.legend(bbox_to_anchor=(1.02, 1), loc=2, borderaxespad=0.,

# Set the title and axis labels
ax.set_title('Yearly Patterns Repeat')

# Shrink the x-axis labels so the month names fit

plt.show()

The Correlation Stories

A correlation story answers do these two things move together? Scatter plots show the raw relationship between two numeric variables. When there are too many points, hexbin plots show density instead. When both variables are categorical, cross-tabulate them and show the table as a heat map.

Candidates: Figure 12, Figure 13, Figure 14, Figure 15, Figure 16, Figure 17.

# Load the example datasets used in this section
mpg = sns.load_dataset('mpg')
penguins = sns.load_dataset('penguins')
diamonds = sns.load_dataset('diamonds')
titanic = sns.load_dataset('titanic')
crashes = sns.load_dataset('car_crashes')

Candidate 1: Scatter Plot With Trend Line

The classic correlation visual. The trend line and the correlation coefficient give the audience a number to remember.

# Compute the correlation between weight and mpg
r = mpg['weight'].corr(mpg['mpg'])

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Scatter plot with a regression line
sns.regplot(data=mpg, x='weight', y='mpg',
            scatter_kws={'s': 15, 'alpha': 0.6},
            line_kws={'color': 'darkred'}, ax=ax)

# Print the correlation coefficient in the corner
ax.text(0.95, 0.95, 'r = {:.2f}'.format(r),
        transform=ax.transAxes, ha='right', va='top', size='small')

# Set the title and axis labels
ax.set_title('Heavier Cars Are Less Efficient')
ax.set_xlabel('Vehicle Weight (lbs)')
ax.set_ylabel('Fuel Efficiency (MPG)')

plt.show()

Candidate 2: Scatter Plot That Reverses Within Groups

Color the points by a third variable to show that a correlation can change direction once the groups are separated (Simpson’s paradox). The dashed line is the overall trend.

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Scatter plot colored by species
sns.scatterplot(data=penguins, x='bill_length_mm', y='bill_depth_mm',
                hue='species', style='species', ax=ax)

# Overall trend line that ignores species
sns.regplot(data=penguins, x='bill_length_mm', y='bill_depth_mm',
            scatter=False, color='black',
            line_kws={'linestyle': '--'}, ax=ax)

# Move the legend into an empty corner
ax.legend(loc='lower left', fontsize='xx-small')

# Set the title and axis labels
ax.set_title('Overall Trend Reverses Within Species')
ax.set_xlabel('Bill Length (mm)')
ax.set_ylabel('Bill Depth (mm)')

plt.show()

Candidate 3: Hexbin Plot For Crowded Scatter Plots

With tens of thousands of points a scatter plot becomes a solid blob. A hexbin plot counts the points in each hexagon so the density shows through.

# Create a pair of side-by-side axes
fig, axes = plt.subplots(nrows=2, figsize=(6, 5), sharex=True, sharey=True)

# Left: plain scatter plot
sns.scatterplot(data=diamonds, x='carat', y='price',
                s=5, ax=axes[0])
axes[0].set_title('Scatter: Overplotted', fontsize='x-small')

# Right: hexbin plot with a log-scaled color bar
hb = axes[1].hexbin(diamonds['carat'], diamonds['price'],
                    gridsize=30, cmap='Blues', mincnt=1, bins='log')
fig.colorbar(hb, ax=axes[1], label='log10(Diamonds)')
axes[1].set_title('Hexbin: Shows Density', fontsize='x-small')

# Set the axis labels
axes[0].set_xlabel('Carat', fontsize='x-small')
axes[1].set_xlabel('Carat', fontsize='x-small')
axes[0].set_ylabel('Price (US dollars)', fontsize='x-small')

plt.show()

Candidate 4: Correlation Matrix Heat Map

A heat map of correlation coefficients shows many relationships at once. Masking the upper triangle removes the duplicated half.

# Compute the correlation matrix
cols = ['mpg', 'cylinders', 'displacement',
        'horsepower', 'weight', 'acceleration']
corr = mpg[cols].corr()

# Hide the upper triangle
mask = np.triu(np.ones_like(corr, dtype=bool), k=1)

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Heat map with the coefficients printed in each cell
sns.heatmap(corr, mask=mask, annot=True, fmt='.2f',
            cmap='coolwarm', vmin=-1, vmax=1, cbar=False,
            annot_kws={'size': 11}, ax=ax)

# Set the title and tick labels
ax.set_title('Heavy Cars Have Low MPG')
ax.tick_params(axis='both', labelsize='x-small')
ax.set_xticklabels(ax.get_xticklabels(), rotation=45)

plt.show()

Candidate 5: Cross-Tabulation Heat Map For Categories

When both variables are categorical, count (or take percentages of) every combination with a cross-tabulation, then color the table.

# Cross-tabulate class by port, as a percent of each port
ct = pd.crosstab(titanic['class'], titanic['embark_town'],
                 normalize='columns').mul(100)
ct = ct.reindex(['First', 'Second', 'Third'])

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Build text labels that end with a percent sign
pct_labels = ct.round(0).astype(int).astype(str) + '%'

# Heat map with the percents printed in each cell
sns.heatmap(ct, annot=pct_labels, fmt='', cmap='Blues',
            cbar=False, annot_kws={'size': 16}, ax=ax)

# Set the title and axis labels
ax.set_title('Class By Embarkation Point')
ax.set_xlabel('Port of Embarkation (% of port)')
ax.set_ylabel('Passenger Class')
ax.tick_params(axis='both', labelsize='x-small')

plt.show()

Candidate 6: Bubble Chart

A third numeric variable can ride along as the size of each point.

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Bubble chart with speeding as the bubble size
sns.scatterplot(data=crashes, x='alcohol', y='total',
                size='speeding', sizes=(20, 300), alpha=0.5,
                edgecolor='k', legend='brief', ax=ax)

# Shrink the legend and place it in an empty corner
sns.move_legend(ax, 'lower right', fontsize='xx-small',
                title='Speeding', title_fontsize='xx-small')

# Set the title and axis labels
ax.set_title('More Alcohol, More Fatal Crashes')
ax.set_xlabel('Alcohol-Impaired Crashes (per billion miles)', fontsize='x-small')
ax.set_ylabel('Fatal Crashes (per bil miles)', fontsize='x-small')
ax.xaxis.label.set_size('small')
ax.yaxis.label.set_size('small')

plt.show()

The Distribution Stories

A distribution story answers what does this one variable look like? Where is the center, how wide is the spread, is it skewed, does it have more than one peak? Histograms, solo box plots, and solo violin plots are the workhorses.

Candidates: Figure 18, Figure 19, Figure 20, Figure 21, Figure 22, Figure 23.

# Load the example datasets used in this section
diamonds = sns.load_dataset('diamonds')
tips = sns.load_dataset('tips')

geyser = sns.load_dataset('geyser')

# Compute the mean and median price
mean_price = diamonds['price'].mean()
median_price = diamonds['price'].median()

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Histogram with a density curve

Candidate 2: Same Data, Different Bin Counts

The number of bins is a choice, and the choice changes the story. This is a good figure for teaching that point.

# Three bin counts to compare
bin_counts = [5, 15, 40]

# Create a row of three axes
fig, axes = plt.subplots(nrows=3, figsize=(6, 9))

# Draw the same histogram with a different number of bins in each
for ax, b in zip(axes, bin_counts):
    sns.histplot(data=tips, x='total_bill', bins=b, ax=ax)
    ax.set_title('{} Bins'.format(b))
    ax.set_xlabel('Bill (dollars)')
    ax.set_ylabel('Number of Bills')

# Label the shared y axis once
fig.suptitle('Bin Count Changes What You See', y=1.03)

plt.tight_layout()
plt.show()

Candidate 3: Solo Box Plot With Labeled Quartiles

A single box plot with the key values printed on it lets the audience read the numbers instead of estimating them.

# Compute the quartiles
q1, med, q3 = tips['total_bill'].quantile([0.25, 0.5, 0.75])

# Create a figure and axis object
fig, ax = plt.subplots(figsize=(6, 3))

# Single horizontal box plot
sns.boxplot(data=tips, x='total_bill', width=0.4,
            color=sns.color_palette('pastel')[0], ax=ax)

# Label each quartile below the box
# for label, val in [('Q1', q1), ('Median', med), ('Q3', q3)]:
for val in [q1, med, q3]:
    ax.text(val*.85, 0.2, '${:.2f}'.format(val),
            transform=ax.get_xaxis_transform(),
            ha='center', va='center', size='xx-small',
            rotation=45)

for val, label in zip([q1, med, q3], ['25th Pctl', '50th Pctl', '75th Pctl']):
    ax.text(val*.95, .83, label,

Candidate 1: Sankey Diagram

A Sankey diagram shows how a population flows through the stages of a process. The thickness of each ribbon is the number of people (or items) that took that path. Matplotlib has no full-featured Sankey function, so this one is drawn with a short helper.

# Build a table of the three stages in the flow
flow = pd.DataFrame({
    'Class': titanic['class'].astype(str),
    'Sex': titanic['sex'].str.title(),
    'Outcome': titanic['alive'].map({'yes': 'Survived', 'no': 'Did Not Survive'})})

# The stages (in order) and the categories to show within each stage
stages = ['Class', 'Sex', 'Outcome']
order = {'Class': ['First', 'Second', 'Third'],
         'Sex': ['Female', 'Male'],
         'Outcome': ['Survived', 'Did Not Survive']}

# One color for every category
palette = dict(zip(
    ['First', 'Second', 'Third', 'Female', 'Male', 'Survived', 'Did Not Survive'],
    sns.color_palette('Set2', 7)))

# Helper that draws the nodes and the ribbons between them
def draw_sankey(ax, df, stages, order, palette, width=0.12):
    gap = 0.04 * len(df)

    # Stack the nodes in each stage and remember where each one sits
    pos, size = {}, {}
    for stage in stages:
        y = 0
        for cat in order[stage]:
            pos[(stage, cat)] = y
            size[(stage, cat)] = (df[stage] == cat).sum()
            y += size[(stage, cat)] + gap

    # Track how much of each node has been used by ribbons so far
    out_used = dict(pos)
    in_used = dict(pos)

    # Draw the ribbons between each pair of neighboring stages
    for i in range(len(stages) - 1):
        a, b = stages[i], stages[i + 1]
        for ca in order[a]:
            for cb in order[b]:
                n = ((df[a] == ca) & (df[b] == cb)).sum()
                if n == 0:
                    continue
                y0, y1 = out_used[(a, ca)], in_used[(b, cb)]
                out_used[(a, ca)] += n
                in_used[(b, cb)] += n
                t = np.linspace(0, 1, 60)
                s = t * t * (3 - 2 * t)
                bottom = y0 + (y1 - y0) * s
                ax.fill_between(i + width + (1 - width) * t,
                                bottom, bottom + n,
                                color=palette[ca], alpha=0.5, linewidth=0)

    # Draw the nodes and label them with the category and count
    for i, stage in enumerate(stages):
        for cat in order[stage]:
            key = (stage, cat)
            ax.add_patch(Rectangle((i, pos[key]), width, size[key],
                                   color=palette[cat]))
            ax.text(i + width / 2, pos[key] + size[key] / 2,
                    '{}\n{}'.format(cat, size[key]),
                    ha='center', va='center', size='xx-small',
                    bbox=dict(boxstyle='round', fc='white', ec='none', alpha=0.8))

    # Name each stage along the bottom
    ax.set_xticks([i + width / 2 for i in range(len(stages))])
    ax.set_xticklabels(stages)
    ax.set_xlim(-0.1, len(stages) - 1 + width + 0.1)
    ax.set_yticks([])

# Create a figure and axis object
